# 🐍 Python Nest

Bem-vindo ao **Python Nest**, um repositório dedicado à documentação e acompanhamento dos meus estudos com a linguagem **Python** — e aberto à comunidade!

Aqui você encontrará projetos, anotações e exemplos práticos, todos organizados de forma modular, com cada exemplo/projeto rodando de maneira independente via ambientes virtuais e `pip`/`poetry`.

---

## 📁 Estrutura do Repositório

Cada diretório de nível superior corresponde a um projeto ou exemplo independente, com seu próprio ambiente e dependências. Isso permite que cada módulo seja explorado, executado e testado individualmente, facilitando a aprendizagem incremental e o reaproveitamento de código.

```
.
├── projeto-1/
│   ├── pyproject.toml
│   ├── requirements.txt
│   └── src/
├── projeto-2/
│   ├── pyproject.toml
│   ├── requirements.txt
│   └── src/
├── docs/
│   └── anotações.md
└── README.md
```

Para executar qualquer projeto:

```sh
cd projeto-1
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python src/main.py
```

## 🐍 Por que Python?

Na minha opinião, Python se destaca pela sua legibilidade, versatilidade e pela enorme comunidade que sustenta um ecossistema riquíssimo de bibliotecas para praticamente qualquer domínio — de automação a ciência de dados, de web a IA.

| Ferramenta | Papel no ecossistema |
|---|---|
| **pip / poetry / uv** | Gestão de dependências e ambientes virtuais |
| **black** | Formatação automática e padronizada de código |
| **ruff / flake8** | Linting rápido e detecção de problemas |
| **mypy** | Checagem estática de tipos |
| **pytest** | Testes simples, expressivos e extensíveis |
| **pyenv** | Gerenciamento de múltiplas versões do Python |
| **IPython / Jupyter** | Exploração interativa e prototipação rápida |

Para mim, o grande diferencial é a filosofia da linguagem: código que se lê quase como pseudocódigo, um design que prioriza clareza (o "Zen do Python") e uma curva de aprendizado suave sem abrir mão de poder para projetos complexos.

Além disso, a comunidade Python é acolhedora, madura e extremamente ativa — o que faz toda diferença para quem está aprendendo ou buscando evoluir na linguagem.
